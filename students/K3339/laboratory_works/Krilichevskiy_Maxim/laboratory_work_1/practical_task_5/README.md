# Практическое задание 5. HTTP-сервер

Запустите `LR1_5_server` в Rider и откройте `http://127.0.0.1:5005/`.
Повторное добавление дисциплины накапливает оценки в одной строке: `МатАн — 5, 4, 5`. Данные хранятся до остановки сервера.

## Структура по учебному каркасу

Класс `MyHTTPServer` объединяет данные сервера и шесть методов:

1. `serve_forever()` принимает подключения в цикле.
2. `serve_client()` обрабатывает одно соединение и закрывает его.
3. `parse_request()` читает строку запроса, разбирает URL и читает тело по `Content-Length`.
4. `parse_headers()` читает заголовки до пустой строки и сохраняет их в словарь.
5. `handle_request()` обрабатывает GET (таблица) или POST (добавление оценки).
6. `send_response()` отправляет строку статуса, заголовки, пустую строку и HTML.

`self` означает текущий экземпляр сервера; `self.grades` — его словарь оценок. Запрос хранится в словаре. Обработчик возвращает статус, текст и дополнительные заголовки.

POST принимает `subject` и `grade` из HTML-формы или URL. Ответ `303` возвращает браузер к GET, чтобы обновление страницы не повторяло добавление. Допустимы оценки от 2 до 5.

Служебные строки HTTP используют ISO-8859-1, HTML — UTF-8. Сокет читается через `makefile("rb")`. Сервер обрабатывает один запрос на соединение; keep-alive и chunked-передача не реализованы.
