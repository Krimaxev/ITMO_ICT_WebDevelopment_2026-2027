# Запуск лабораторной работы №1 в Rider

В списке Run Configurations выберите конфигурации из папки **Лабораторная 1** с префиксом `LR1_`.
Они сохранены в `.run`, указывают на интерпретатор `.venv1/bin/python` и рабочую папку соответствующего задания.
Если новые конфигурации ещё не появились, переоткройте проект.

| Задание | Что запустить | Адрес |
| --- | --- | --- |
| 1: UDP | `LR1_1_server`, затем `LR1_1_client` | 127.0.0.1:5000 (UDP) |
| 2: площадь | `LR1_2_server`, затем `LR1_2_client` | 127.0.0.1:5001 |
| 3: HTML | `LR1_3_server`, затем открыть браузер | http://127.0.0.1:5003/ |
| 4: чат | `LR1_4_server`, затем несколько `LR1_4_client` | 127.0.0.1:5004 |
| 5: оценки | `LR1_5_server`, затем открыть браузер | http://127.0.0.1:5005/ |

- Для клиента чата включён запуск нескольких экземпляров. Каждый участник вводит имя в своей консоли. Выход — `/exit`.
- Для каждого сервера запуск нескольких экземпляров запрещён. Пользуйтесь одной конфигурацией `LR1_`, не запускайте тот же сервер одновременно через старую конфигурацию или терминал.
- Серверы заданий 1 и 2 завершаются после одного обмена. Перед следующим запуском клиента запускайте сервер снова.
- Серверы 3–5 работают до нажатия Stop. Не останавливайте их перед открытием страницы или запуском клиентов.
- `Address already in use` означает, что другой процесс уже занимает этот порт. Остановите предыдущий запуск того же задания; менять порт не требуется.
- После остановки сервера задания 5 добавленные оценки сбрасываются.
